Paper Corollary 7.46. complete conditional implication.

For \(1{\lt}p\leq 2\),

\begin{align} \| A_T^*f\| _{L^p(X)} \leq \exp \left( \frac{C}{p-1}\log \frac{e}{p-1} \right)\| f\| _{L^p(X)}. \end{align}

Moreover,

\begin{align} \mu \{ A_T^*f{\gt}\lambda \} \ll \int _X\Psi _C\left(\frac{|f|}{\lambda }\right)\, d\mu , \qquad \lambda {\gt}0. \end{align}

If \( \int _X\Psi _C(|f|/a)\, d\mu {\lt}\infty \) for some \(a{\gt}0\), then the corresponding averages converge almost everywhere and in \(L^1(X)\).

Proof architecture ▼

Apply the explicit strong and modular transference interfaces on invertible probability systems. Approximate by bounded truncations and combine the modular maximal control with the independent bounded-class convergence theorem. Prove the Cauchy and density-extension steps for the unbounded Orlicz class; those conclusions are not supplied as external inputs.

Paper Theorem 1.5. complete conditional implication.

Let \(p_k\) denote the \(k\)-th prime, and put \(n_k=p_k^2\).

  1. The sequence \((n_k)\) is persistently universally \(L^1\)-bad. More precisely, for every nonatomic ergodic measure-preserving probability system \((X,\mu ,T)\) and every infinite set \(\mathcal S\subset \mathbb N\), there is an \(f\in L^1(X)\) for which

    \[ \frac1N\sum _{k\leq N}f(T^{n_k}x), \qquad N\in \mathcal S, \]

    diverges on a set of positive measure.

  2. There is an absolute constant \(C{\gt}0\) such that, for every invertible measure-preserving probability system \((X,\mu ,T)\), every \(1{\lt}p\leq 2\), and every \(f\in L^p(X)\),

    \[ \left\| \sup _{N\geq 1} \left|\frac1N\sum _{k\leq N}f(T^{n_k}x)\right| \right\| _{L^p(X)} \leq \exp \left( \frac{C}{p-1}\log \frac{e}{p-1} \right) \| f\| _{L^p(X)}. \]
Proof architecture ▼

For part (i), use the persistent arithmetic criterion on arbitrary nonatomic ergodic probability systems. For part (ii), use strong transference on invertible systems and identify enumerated-prime averages exactly with the appropriate prime cutoffs. Preserve the different system hypotheses of the two parts; a numerical prime-cutoff approximation would not suffice.
