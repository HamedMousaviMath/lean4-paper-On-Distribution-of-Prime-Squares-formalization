Paper Theorem 1.6. complete conditional implication.

Almost all integers congruent to \(12\) modulo \(24\) can be written as

\[ a^2+b^2+p^2+1, \qquad a^2+b^2+1\in \mathcal P,\quad p\in \mathbb P. \]

More precisely, if

\[ E_2(X)=\{ 1\leq n{\lt}X:n\equiv 12\pmod{24}, n\notin \mathcal P+\mathbb P^2\} , \]

then, for every \(A{\gt}0\),

\[ |E_2(X)|\ll _A X(\log X)^{-A}. \]
Proof architecture ▼

Insert the lower and upper sieve estimates into the exact master inequality and use the strict positive margin. Absorb all mean-square error sets with the requested logarithmic saving. Pass from square cutoffs to arbitrary real \(X\) and identify the source exceptional set literally. The theorem uses \(n\equiv 12\pmod{24}\); subtracting one gives the explanatory version in the abstract.
