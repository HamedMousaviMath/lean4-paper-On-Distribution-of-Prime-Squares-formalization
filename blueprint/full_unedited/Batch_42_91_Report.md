# Prime Squares: combined report for checkpoints 42–91

Fifty separately saved proof checkpoints continue checkpoint 41. This batch adds 95 named supporting theorems in 50 modules; the project now has 940 named supporting theorems in 158 modules. These counts describe supporting formal work, not newly completed numbered manuscript results.

## What this batch establishes

1. The genuine finite real model's major-arc error has a logarithmic rate with a single natural-number threshold independent of Q, the chosen finite rational-center set and exceptional data, conditional on the explicitly displayed actual progression-prefix estimate.
2. Actual annular integrals and localized Gauss models are continuous in frequency. Their compact symbols have a genuine continuous unit-circle periodization, globally identified with the integer-translate sum. Boundary aliases are included.
3. Finite rational-center sums define genuine global continuous model, error, low and high candidate symbols. Their inverse Fourier kernels and compatible l1-to-linfinity / l2 operators are constructed. The actual annular von-Mangoldt square kernel and every finite complex input have exact low + high + error decompositions.
4. Infinite convolution by a bounded kernel is proved absolutely convergent on every l1 input. The resulting bounded linear operator agrees with the Fourier l2 operator on finite inputs. Kernel-sensitive bounds, denominator-weighted Gauss estimates and finite-family l2 envelopes are proved.
5. The narrow-to-broad cutoff containment is proved. The compact low and high real symbols equal the original paper formulas under the displayed scalar conditions, including Q*q0/B0<=R for the exceptional width. This condition is not silently inferred from unproved conductor data.
6. An explicit assembly theorem connects these actual operators to OperatorHighLowBound at the correct spatial scale N^2. Its sharp low-kernel and combined high/error-symbol bounds remain displayed inputs, not proved source estimates.
