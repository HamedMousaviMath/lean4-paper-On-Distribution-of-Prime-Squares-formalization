# Checkpoint 371: The genuine weighted fixed-cutoff circle collar maximum

For bounded complex scale coefficients, the actual weighted circle collars admit a countable pointwise l2 maximum with norm at most 24bq/(pi Q) times the input norm. This is an actual fixed-Q maximum for the collar contribution. It does not establish the full high operator, whose large-denominator terms need separate estimates.
